# インストール手順

## Chrome / Edge

1. Chrome/Edgeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. この `extension` ディレクトリを選択

## Firefox

1. Firefoxで `about:debugging` を開く
2. 「このFirefox」タブを選択
3. 「一時的なアドオンを読み込む」をクリック
4. `extension/manifest.json` を選択

## 使用方法

1. YouTubeにログインしてください
2. Rushia DLのWebページを開いてください
3. 「Cookieを自動取得」ボタンをクリックしてください
4. 自動的にCookieが取得・アップロードされます

## トラブルシューティング

### 拡張機能が認識されない場合

- 拡張機能が有効になっているか確認してください
- ブラウザを再起動してください
- 拡張機能を再インストールしてください

### Cookieが取得できない場合

- YouTubeにログインしているか確認してください
- ブラウザのCookieが有効になっているか確認してください
- シークレットモードでは動作しない場合があります
